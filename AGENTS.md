# Spotter — project rules

Source of truth: SPOTTER_SPEC.md. Read it before starting any task.

## Non-negotiable rules
- Never hard-code commentary or insights. Only match events follow the script; agents discover insights from data via tools.
- Use only the fictional squads in the spec. No real clubs, players, Premier League branding, or copyrighted assets.
- All data is generated by code with seed=42; aggregates are always derived, never typed in.
- Never commit `.env` or secrets. `.env` must be in `.gitignore`.
- Check current Microsoft Agent Framework docs before using its API. Don't guess method names.

## Cost guard (required)
- After every LLM call, read token usage from the response and compute cost:
  gpt-5-mini $0.275/M input, $2.20/M output; gpt-5-nano $0.05/M input, $0.40/M output.
- Count TTS characters at $15/M.
- Add to a running total persisted in `backend/app/data/cost_ledger.json`.
- If the total reaches `COST_CAP_USD` (env, default 8): stop all LLM and TTS calls, fall back to
  templates and subtitles only, and broadcast a "cost cap reached" status so the UI shows a badge.
- All LLM and TTS calls must go through one wrapper module (`backend/app/llm.py`) that enforces this.
  No direct model or speech client calls anywhere else.

## Deployment
- Azure Container Apps: min replicas 0, max replicas 1 (scale to zero).
